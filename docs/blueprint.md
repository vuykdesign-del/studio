# **App Name**: Tracker de Panza

## Core Features:

- Contraction Tracking: Record the start and end times of contractions with a single tap.
- Duration Calculation: Automatically calculate the duration of each contraction.
- Interval Calculation: Automatically calculate the interval between contractions.
- Real-time Timer: Display a real-time timer for tracking contraction duration.
- Historical Data: Save all the contraction timings in the Firestore database.
- Last Hour Summary: Calculate and display average contraction frequency and duration for the last hour.
- Data Persistence: Store contraction data in Firestore with local storage fallback.

## Style Guidelines:

- Dark mode theme to follow the reference images, providing a high-contrast interface suitable for nighttime use.
- Primary color: Coral (#FF7F50) for interactive elements and important data.
- Background color: Dark gray (#121212) to provide a true dark mode experience, and increased contrast.
- Accent color: Mint green (#98FF98) to highlight calculated values and timers.
- Font: 'Inter' sans-serif font for both body and headlines for clarity.
- Display data and key labels in a large, legible font.
- Simple, easily recognizable icons for tab navigation.
- Large, circular primary button for starting and stopping contractions. Minimize on-screen clutter, focus on key elements. Replicate the layout of the reference image
- Subtle animation/glow effects on the main button while tracking a contraction.
